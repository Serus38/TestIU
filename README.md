# Prueba Técnica

## Descripción

Ejercicio de replica para prueba técnica. Plataforma web interactiva que presenta una interfaz educativa. Este proyecto demuestra habilidades en maquetación HTML5 semántica, diseño responsivo con CSS3, componentes interactivos y optimización de UX/UI.

## Objetivos del Ejercicio

- **HTML5 Semántico**: Estructura correcta
- **CSS3 Avanzado**: Variables CSS, grid layout, flexbox y animaciones
- **Diseño Responsivo**: Interfaz adaptada para múltiples dispositivos
- **Accesibilidad**: Cumplimiento de estándares de accesibilidad web
- **Componentes Visuales**: Integración de SVG, imágenes y animaciones suaves

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica del proyecto
- **CSS3**: Estilos avanzados con variables CSS personalizadas y animaciones
- **SVG e Imágenes**: Elementos visuales personalizados

## Estructura del Proyecto

```
TestIU/
├── index.html           # Página principal
├── README.md            # Este archivo
├── css/
│   └── styles.css       # Estilos principales
├── js/
│   └── script.js        # Funcionalidades JavaScript (No implementado en este caso)
├── fonts/               # Fuentes personalizadas (Lato-Regular)
└── img/                 # Recursos gráficos (SVG e imágenes)
```


## Habilidades Demostradas

- HTML5
- CSS Grid y Flexbox para layouts complejos
- Variables CSS para mantener consistencia de estilos
- Animaciones CSS
- Diseño móvil responsive
- Estructura de proyecto bien organizada
- Atención al detalle en UI/UX
